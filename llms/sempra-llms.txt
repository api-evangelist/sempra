# Sempra

> and a Fortune 500 constituent, operating regulated utilities and energy infrastructure

## What is callable today

- [Sempra Developer Portal APIs](https://developer.sempra.com): a Google Apigee program.
  A live OAuth 2.0-protected proxy is routed at https://api.sempra.com/v1 — every path
  under /v1 returns HTTP 401 with an Apigee `oauth.v2.InvalidAccessToken` fault and an
  RFC 6750 `WWW-Authenticate: Bearer` challenge, while `/`, `/v2/*`, `/oauth/token` and
  `/openapi.json` return the Apigee `messaging.adaptors.http.flow.ApplicationNotFound`
  not-routed 404. There is a real API. There is no way to learn what it does without
  registering.
